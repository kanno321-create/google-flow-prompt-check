# Google Flow 프롬프트 점검 — 무료 Claude Code 스킬

[日本語](README.ja.md) · [English](README.md) · **한국어**

Google Flow(Veo)나 Kling 프롬프트를 **생성** 버튼을 누르기 전에 Claude Code 에 붙여 넣으세요.
크레딧을 가장 많이 날린 일곱 가지 원인에 비춰 보고, 걸린 문장만 고쳐 씁니다. 나머지 말은 그대로 둡니다.

저희는 Google Flow 와 Kling 으로 역사·건축 쇼츠를 만듭니다. 이 일곱 가지는 실제로 버린 컷에서 골랐습니다.

## 점검하는 것

| # | 원인 | 스킬이 바꾸는 것 |
|---|---|---|
| 1 | 스틸을 다 갖춰 확인하기 전에 영상부터 만든다 | 순서 제안: 모든 컷의 스틸 → 나란히 놓고 확인 → 영상 |
| 2 | 여러 컷에 나오는 건물에 기준 이미지가 없다 | 실제 사진 2~4장으로 기준 이미지 한 장, «바뀌지 않는 부분» 말을 매번 프롬프트에 |
| 3 | 크기를 «거대한», «우뚝 솟은»으로 쓴다 | 사람 몸으로 셈: «어른 일곱 명을 쌓은 높이» |
| 4 | 영상 한 개에 카메라 움직임이 둘 / 멈추는 법이 없다 | 움직임 하나, «마지막 1초에 세게 감속해 …에서 멈춘다»로 끝냄 |
| 5 | 처음과 끝 상태가 너무 멀다 | 변화를 작게, 또는 컷 두 개로 |
| 6 | 화면 안에 글자를 넣으려 한다 | «글자 없음», 화면 위쪽 5분의 1 비움. 글자는 편집 프로그램에서 |
| 7 | 거절되기 쉬운 낱말 | 부상·붉게 물든 손·어른 바로 옆의 아이·실존 인물 이름·얼굴 클로즈업을 뺌 |

이미 실패한 컷이면 본 것(«카메라가 흘렀다», «사람이 녹았다», «물이 거칠어졌다»)을 말해 주세요. 그 원인이 되는 문장을 고칩니다.

## 설치

Claude Code 가 필요합니다(Claude 유료 요금제, Pro 이상 — [요금](https://claude.com/pricing) · [내려받기](https://claude.com/download)).

1. 이 페이지의 초록색 **Code** 버튼 → **Download ZIP** 으로 받아서 압축을 풉니다.
2. `.claude/skills/flow-prompt-check` 폴더를 둘 중 한 곳에 복사합니다(점으로 시작하는 폴더는 Mac 에서 숨겨져 있습니다. Finder 에서 Cmd + Shift + . 을 누르면 보입니다).
   - `~/.claude/skills/` — 모든 프로젝트에서 쓰려면
   - `<내 프로젝트>/.claude/skills/` — 그 프로젝트에서만 쓰려면
3. Claude Code 를 켜고 `/flow-prompt-check` 를 입력한 뒤 프롬프트를 붙여 넣습니다.

압축을 푼 이 폴더를 그대로 Claude Code 로 열어도 됩니다.
