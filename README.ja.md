# Google Flow プロンプトチェック — 無料の Claude Code スキル

**日本語** · [English](README.md) · [한국어](README.ko.md)

Google Flow（Veo）や Kling のプロンプトを、**生成**を押す前に Claude Code に貼ってください。
クレジットをいちばん無駄にした7つの原因と照らし合わせて、引っかかった文だけを書き直します。ほかの言葉はそのまま残します。

私たちは Google Flow と Kling で、歴史や建物のショート動画を作っています。この7つは、実際にボツにしたカットから選びました。

## 確かめること

| # | 原因 | スキルが変えること |
|---|---|---|
| 1 | 静止画をそろえて確かめる前に動画を作っている | 順番を提案：全カットの静止画 → 並べて確認 → 動画 |
| 2 | 何度も出る建物に基準画像がない | 実物の写真2〜4枚から基準画像を1枚、「変わらない部分」の言葉を毎回のプロンプトに |
| 3 | 大きさを「巨大な」「そびえ立つ」で書いている | 人の体で数える：「大人7人分の高さ」 |
| 4 | 1本の動画にカメラの動きが2つ／止まり方がない | 動きは1つ、「最後の1秒で強く減速して〜で止まる」で終える |
| 5 | 最初と最後の状態が離れすぎている | 変化を小さく、または2カットに分ける |
| 6 | 画面の中に文字を入れようとしている | 「文字なし」、画面の上の5分の1を空ける。文字は編集ソフトで |
| 7 | 断られやすい言葉 | けが・赤く染まった手・大人のすぐそばの子ども・実在の人の名前・顔のアップを外す |

すでに失敗したカットなら、見えたこと（「カメラが流れた」「人が溶けた」「水が荒れた」）を伝えると、その原因の文を直します。

## 入れ方

Claude Code が必要です（Claude の有料プラン、Pro 以上 — [料金](https://claude.com/pricing)・[ダウンロード](https://claude.com/download)）。

1. このページの緑の **Code** ボタン → **Download ZIP** でダウンロードし、ZIP を展開します。
2. `.claude/skills/flow-prompt-check` フォルダを、次のどちらかにコピーします（点で始まるフォルダは Mac では隠れています。Finder で Cmd + Shift + . を押すと見えます）。
   - `~/.claude/skills/` — どのプロジェクトでも使う場合
   - `<自分のプロジェクト>/.claude/skills/` — そのプロジェクトだけで使う場合
3. Claude Code を起動し、`/flow-prompt-check` と入力して、プロンプトを貼ります。

展開したこのフォルダをそのまま Claude Code で開いても使えます。
